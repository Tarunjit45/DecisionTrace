## 📌 Overview

DecisionTrace is a simple, powerful tool for creating an audit trail of your AI's decisions. Think of it as a flight data recorder for your AI.

## ✨ Key Features & Architecture

- **High-Performance Architecture:** Engineered using modern `Python` best practices.
- **Modular & Scalable Design:** Structured code organization for easy maintenance and deployment.

## 🚀 Getting Started

### Prerequisites
- Python 3.9+
- pip package manager

### Installation & Local Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Tarunjit45/DecisionTrace.git
   cd DecisionTrace
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the application:**
   ```bash
   python main.py
   ```
